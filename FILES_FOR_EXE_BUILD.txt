AVL-DRIVE Heatmap Tool V5.1 — files required to build the Windows .exe
================================================================================

Get the latest code:
  git clone https://github.com/shubhamsayal05-boop/excel-to-python.git
  cd excel-to-python
  git checkout cursor/add-gearshift-sub-operations-1720
  git pull

Or download branch zip from GitHub and extract to e.g. C:\Tools\AVL-Heatmap-Tool\
(Do NOT use a double-nested folder like "project (1)\project\".)


REQUIRED FILES (all in one folder)
----------------------------------

Build scripts:
  build_exe.bat                    ← double-click this to build
  AVL-DRIVE-Heatmap-Tool.spec      ← PyInstaller configuration
  requirements.txt                 ← app dependencies
  requirements-build.txt         ← build dependencies (pyinstaller)
  export_operation_modes.py        ← generates operation_modes.json before build

EXE entry + bundle loader:
  launcher.py                      ← EXE entry point (starts Streamlit)
  bundle_loader.py                 ← loads app modules inside the bundle

Application (bundled into _internal):
  app.py
  config.py
  heatmap_engine.py
  evaluation_engine.py
  heatmap_excel_export.py
  operation_modes.json             ← generated by export_operation_modes.py

Optional (not bundled):
  tests\
  README.md


BUILD STEPS (Windows)
---------------------
1. Install Python 3.10+ from https://www.python.org/downloads/
   (check "Add Python to PATH")

2. Open Command Prompt in the project folder:
   cd C:\Tools\AVL-Heatmap-Tool

3. Run:
   build_exe.bat

4. When you see SUCCESS, run:
   dist\AVL-DRIVE-Heatmap-Tool\AVL-DRIVE-Heatmap-Tool.exe

5. Distribute the ENTIRE folder:
   dist\AVL-DRIVE-Heatmap-Tool\
     AVL-DRIVE-Heatmap-Tool.exe
     _internal\                 ← required


BUILD MUST SHOW
-----------------
  OK: python310.dll found          (or python311.dll etc.)
  OK: vcruntime140.dll found
  OK: operation_modes.json contains Upshift 10090100
  OK: _tcl_data bundled
  SUCCESS.


IF EXE FAILS AT STARTUP
-----------------------
Install VC++ Redistributable x64:
  https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist

Do not run streamlit run app.py and the EXE at the same time.


VERIFY IN APP (Help & Reference)
--------------------------------
  Bundle stamp: gearshift-json-v3
  Rows include 10090100 Upshift and 10090200 Downshift
